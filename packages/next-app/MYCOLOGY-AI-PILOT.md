# Mycology AI Pilot Scaffold

Route: `/mycology-ai`  
API boundary: `POST /api/mycology-ai`  
Current state: UI preview only; API intentionally returns HTTP 503.

The interface is not a live AI advisor. The preview question capture is local to the browser and sends no request. Activate the API only after authentication, tenant authorization, approved knowledge retrieval with citations, rate limiting, cost controls, and evaluation are implemented.

See [the implementation plan](../../docs/SOUTHWEST-MUSHROOMS-MYCOLOGY-AI-IMPLEMENTATION.md) for the launch gates and product scope.
